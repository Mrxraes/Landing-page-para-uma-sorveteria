# Landing-page-para-uma-sorveteria
Landing page em HTML para a marca Yooo especializada em milkshakes. Apresenta catálogo de sabores, opções de tamanho (350 ml e 500 ml), seleção de produtos e gerenciamento de carrinho. Inclui finalização de pedidos via WhatsApp e informações sobre atendimento e área de entrega, oferecendo uma experiência digital de consulta e compra para o usuário.
